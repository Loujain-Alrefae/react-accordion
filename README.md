# 🌿 Stna Design System - Accordion Component

A fully customizable and interactive **Accordion Component** built with **React** and **Tailwind CSS**. It provides a flexible, smooth UI/UX for displaying FAQs and structured content, complete with a live customization playground and real-time code generation.

---

## ✨ Key Features

* 🎨 **Interactive Component Playground:**
  * **Visual Styles:** Support for different layout variants (e.g., separated cards).
  * **Icon Customization:** Control icon types and positions (start / end).
  * **Behavioral Controls:** 
    * Allow multiple items to be expanded simultaneously (`multiple mode`).
    * Toggle collapsible behavior upon clicking.
    * Enable smooth animations and transitions.
  * **Structural Flexibility:** Easily select HTML heading levels (h1, h2, h3, etc.).

* 🔍 **Live Search:** Instant filtering and searching through questions and answers.
* ➕ **Add New Questions:** Simple dynamic form to add custom questions and answers to the list in real time.
* 💻 **Live Code Generator:** Displays the generated React/JSX code based on current settings with a one-click copy button.
* 🌐 **Full RTL Support:** Native Right-to-Left design optimized for Arabic and multilingual applications.

---

## 🛠️ Tech Stack

* **React.js** - For building interactive UI components.
* **Tailwind CSS** - For responsive and utility-first styling.
